## 📌 Objective

The goal of this assignment is to implement and compare two models for the
Named Entity Recognition (NER) task:

1. **Hidden Markov Model (HMM)**
2. **Maximum Entropy Markov Model (MEMM)**

NER is the process of identifying named entities (such as people, organizations, and locations) in text and tagging them accordingly.

## 🗂 Tasks

### Task 1: HMM for NER
Implemented a statistical model using a first-order Hidden Markov Model to label each token in a sentence with one of the following tags:
- `PER` (Person)
- `ORG` (Organization)
- `LOC` (Location)
- `MISC` (Miscellaneous)
- `O` (Other)

### Task 2: MEMM for NER
Built a discriminative model using the Maximum Entropy framework to assign labels 
to tokens using local features and context.
